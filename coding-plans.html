Student Pricing Summary

Quick reference for students and educators looking for the best deals.

Best Options for Students (Ranked)

1. GitHub Copilot Student — FREE
The gold standard. Verified students (via GitHub Education) get free Copilot access indefinitely. As of March 2026, the Student plan restricts direct selection of premium models (GPT-5.4, Claude) but Auto mode still routes to them intelligently. You can upgrade to Pro/Pro+ later while keeping your Student Pack.

2. Cursor Pro — FREE for 1 year ($240 value)
Full Pro plan free for 12 months with .edu email + SheerID verification. Includes unlimited tab completions and the full credit-based model access. Available to high school, college, university, and bootcamp students age 13+. Reverts to $20/mo after the free year.

3. Windsurf Pro — ~$6.90/mo (54% off)
Half-price Pro plan for verified students, valid for 12 months and renewable up to 3 times. Limited to first 4,200 signups. Full Pro features including 500 prompt credits/mo.

4. Anthropic Claude — Institutional only
No individual student discount. However, Anthropic offers an Education Plan for universities — check if your school has a partnership that provides free access. Some university partnerships extend through 2027.

5. China-based plans (GLM, MiniMax, Qwen, Kimi) — No student discounts
None offer dedicated edu pricing. However, their base prices are already low ($5–$10/mo at entry tiers), making them accessible regardless. Kimi and Moonshot have Campus Programs for institutional partnerships.

Understanding "Coding Plans"

What is a Coding Plan?

A Coding Plan is a flat-fee monthly subscription from an AI provider that gives you access to their models inside coding tools like Claude Code, Cursor, Cline, and others. Instead of paying per token, you pay a fixed amount and get a prompt/request quota that refreshes on a rolling basis (typically per 5-hour window or monthly).

Important: One "prompt" in a coding agent typically triggers 5–30 underlying model calls. So a plan with "100 prompts per 5 hours" might translate to 500–3,000 actual API calls. This is why flat-fee plans can be dramatically cheaper than pay-as-you-go API pricing for heavy coding use.

IDE-Native vs. API-Backed

IDE-native tools (Cursor, Windsurf, GitHub Copilot) bundle the editor experience with model access — you get autocomplete, inline chat, and agent features in one package. API-backed plans (GLM, MiniMax, Qwen, Kimi) provide an API key you plug into your preferred tool. The latter gives more flexibility but requires setup.

Recent Changes (Q1 2026)

GLM (Z.ai): Prices increased 30–60% effective Feb 11, 2026. First-purchase discounts removed. Lite went from $3 to $9/mo. Quarterly and annual billing discounts added as partial offset.

MiniMax: Coding Plan still runs on M2.1 — the newer M2.5 model (SWE-Bench 80.2%) is only available via pay-as-you-go API. Plan update expected but not yet announced.

Qwen (Alibaba): Newly launched with a 50% promotional discount. Regular prices are $10/mo (Lite) and $50/mo (Pro). Promo pricing brings them to ~$5 and ~$25 respectively.

Cursor: Continues its credit-based model introduced June 2025. "Auto" mode is unlimited; manually selecting premium models draws from your credit pool.

Claude Code: Max plan (5x at $100/mo, 20x at $200/mo) remains monthly-only with no annual billing option.

GitHub Copilot Student (Mar 12): New "Copilot Student" plan replaces the old free tier. Premium model self-selection removed (GPT-5.4, Claude Opus/Sonnet); Auto mode still routes to premium models. Students can upgrade to paid plans while keeping Student Pack benefits.
